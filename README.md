## Finance-API

A backend application built with Node.js and Express.js to manage financial transactions and user accounts.

### Features

- RESTful API architecture
- Modular code structure with controllers, models, routes, and authentication
- User authentication and access control
- Development tools integration with nodemon

### Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/UrmitRaiyani/Finance-API.git
   cd Finance-API
2. Install dependencies: npm install
3.Start the development server: npm run dev
